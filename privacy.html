Privacy Policy.

Last Updated: February 27, 2026 — Effective: February 19, 2024

1. INTRODUCTION

Altair ("we", "our", or "us") is a Discord bot designed for server moderation, automation, and community management. This Privacy Policy explains how we collect, use, store, and protect your information when you use Altair.

2. INFORMATION WE COLLECT

Automatically Collected:

  • Discord User ID, Username, Avatar, Discriminator
  • Server ID, Channel IDs, Role information
  • Message content (for AutoMod, logging, and moderation)
  • Timestamps of user actions (joins, leaves, violations)

Stored Data:

  • Strikes/Warnings — user violations and moderation history
  • Message Logs — deleted/edited messages (if configured)
  • Welcome Config — server-specific settings
  • AutoMod Config — filter lists, thresholds, ignored channels/roles
  • Level Data — XP, level, and rank information
  • Ticket Data — support ticket transcripts and metadata

3. HOW WE USE YOUR INFORMATION

  • Moderation — Enforcing server rules via AutoMod (strikes, timeouts, kicks, bans)
  • Logging — Tracking message edits/deletions for moderation purposes
  • Welcome System — Greeting new members with custom messages
  • Security — Preventing spam, raids, and malicious content
  • Leveling — Tracking engagement and awarding XP/role rewards
  • Analytics — Anonymous statistics on bot usage and performance

4. DATA STORAGE & SECURITY

  • All data is stored locally on the server hosting the bot
  • Data is NOT shared with third parties or external services
  • No cloud storage, no data selling, no advertising
  • JSON database files with restricted file permissions
  • Access limited to bot administrators only

5. DATA RETENTION

Data Type Retention
Strikes & Warnings Permanent until manually reset by admin
Message Logs 30 days automatic rotation
Config Settings Until bot removal from server
User Profiles Cached temporarily, refreshed on demand
Level/XP Data Persistent until admin reset
Ticket Transcripts Until manually deleted

You may request data deletion at any time (see Section 8).

6. YOUR RIGHTS

  • Right to Access — View your stored data via /automod user
  • Right to Rectification — Request correction of inaccurate data
  • Right to Erasure — Request complete deletion of your data
  • Right to Restrict — Opt-out of specific data collection
  • Right to Portability — Export your data in readable format

7. SERVER ADMINISTRATOR CONTROLS

Server owners and admins with Administrator permission can:

  • Configure what data is collected (toggle modules on/off)
  • Set data retention periods
  • Delete user data via /automod reset
  • Export server data for backup
  • Disable data collection entirely via /automod toggle

8. CONTACT & DATA REQUESTS

For privacy inquiries or data requests:

  • Use /privacy in Discord for self-service options
  • Email (Data Protection Officer): altairdiscordbot@gmail.com
  • Join the Support Server for direct assistance
  • Use /bug to contact the development team
  • Deletion requests are typically processed within 48 hours

9. POLICY CHANGES

We may update this Privacy Policy periodically. Changes will be posted on this page, announced in the support server, and dated at the top. Continued use after changes constitutes acceptance.
