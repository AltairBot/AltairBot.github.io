.01

Moderation

Core moderation tools for server administrators. All commands require Administrator permission.

/ban <user> [reason]

Permanently ban a user from your server. Provides a DM notification to the banned user with the reason.

REQUIRES: ADMINISTRATOR

/kick <user> [reason]

Kick a user from the server. They can rejoin with a new invite link.

REQUIRES: ADMINISTRATOR

/clear <amount>

Bulk delete messages in the current channel. Supports up to 100 messages at a time.

REQUIRES: ADMINISTRATOR

.02

AutoMod System

Intelligent automated moderation that runs 24/7. Configurable filters for profanity, spam, links, and invites with customizable thresholds and actions.

/automod setup <log> <mod> [dev]

Initialize the AutoMod system. Set the log channel for violations, mod channel for alerts, and optional dev config channel.

REQUIRES: ADMINISTRATOR

/automod profanity <enabled> [level]

Toggle the profanity filter on or off. Set sensitivity level to Low, Medium, or High.

REQUIRES: ADMINISTRATOR

/automod spam <enabled> [max_messages] [timeframe]

Configure anti-spam. Set how many messages within a timeframe trigger a violation. Includes invite blocking.

REQUIRES: ADMINISTRATOR

/automod links <enabled> [mode]

Control link sharing. Modes: Whitelist (allow only approved domains) or Block All.

REQUIRES: ADMINISTRATOR

/automod actions [warn] [timeout] [kick] [ban]

Enable or disable specific punishment actions when violations are detected.

REQUIRES: ADMINISTRATOR

/automod thresholds [warn] [timeout] [kick] [ban] [duration]

Set strike thresholds before each action triggers. Example: 3 warnings → timeout, 5 → kick.

REQUIRES: ADMINISTRATOR

/automod add <type> <value>

Add items to filter lists. Types: custom word, whitelisted domain, ignored channel, ignored role.

REQUIRES: ADMINISTRATOR

/automod remove <type> <value>

Remove items from filter lists.

REQUIRES: ADMINISTRATOR

/automod user <user>

View a user's strike history and violation report.

REQUIRES: ADMINISTRATOR

/automod reset <user>

Reset all strikes and warnings for a specific user.

REQUIRES: ADMINISTRATOR

/automod stats

View overall AutoMod statistics including total violations, most active filters, and recent activity.

REQUIRES: ADMINISTRATOR

.03

Ticket System

Complete support ticket system with multi-role support, category management, and ticket lifecycle controls.

/tickets setup <channel> [roles...] [title] [description]

Create a ticket panel in the specified channel. Supports up to 4 support roles and 2 admin roles for multi-tier support.

REQUIRES: ADMINISTRATOR

/tickets roles [support_1..4] [admin_1..2]

Edit ticket roles without recreating the panel. Assign which roles get access to new tickets.

REQUIRES: ADMINISTRATOR

/tickets categories [active] [closed]

Set Discord channel categories for open and closed tickets to keep your server organized.

REQUIRES: ADMINISTRATOR

/tickets close [ticket_id]

Force close a ticket. Generates a transcript and moves it to the closed category.

REQUIRES: ADMINISTRATOR

.04

Levels & XP

Engagement-driven leveling system with rank cards, leaderboards, and role rewards. Free tier includes core features; Pro unlocks advanced customization.

FREE

/level rank [user]

View your rank card or another user's. Displays level, XP progress, and server ranking.

REQUIRES: NONE

/level leaderboard

View the server's top 10 XP leaderboard.

REQUIRES: NONE

/level rewards add <role> <level>

Assign a role reward for reaching a level. Free: up to 5 rewards. Pro: unlimited.

REQUIRES: ADMINISTRATOR

/level rewards remove <level>

Remove a role reward from a specific level.

REQUIRES: ADMINISTRATOR

/level rewards list

View all configured level rewards for this server.

REQUIRES: NONE

/level config [enabled] [announce] [stack-roles]

Basic configuration: enable/disable the system, toggle level-up announcements, and set role stacking.

REQUIRES: ADMINISTRATOR

/level set <user> <level>

Manually set a user's level.

REQUIRES: ADMINISTRATOR

/level reset <user>

Reset a user's XP and level progress entirely.

REQUIRES: ADMINISTRATOR

⭐ PRO ONLY

/level leaderboard [page]

Browse unlimited leaderboard pages beyond the top 10 (up to 100 users).

REQUIRES: PRO

/level config [cooldown] [channel] [min-xp] [max-xp] [formula]

Advanced configuration: custom XP cooldown, dedicated level-up channel, custom XP range per message, and formula selection (exponential or linear).

REQUIRES: PRO + ADMINISTRATOR

REQUIRES: NONE

Claim your daily allotment of Orbs. Pro servers receive a 1.5x - 2x multiplier on all claims.

REQUIRES: NONE

/economy leaderboard

View the wealthiest members in the server. Displays the top 10 users by default.

REQUIRES: NONE

/gamble slots <bet>

Play the slot machine. Match 2 symbols to win 2x, or 3 symbols for up to 10x your bet.

REQUIRES: NONE

/gamble coinflip <choice> <bet>

Double or nothing. Bet on Heads or Tails for a 50/50 chance to win.

REQUIRES: NONE

/economy admin give <user> <amount>

Add Orbs to a user's balance. Useful for event rewards or manual corrections.

REQUIRES: MANAGE_SERVER

Reaction Roles

/rr create <channel> <mode> [title] [description] [color]

Initialize a new panel. Modes: Normal (toggle), AddOnly, Unique (one per panel), or Verify (permanent).

REQUIRES: ADMINISTRATOR

/rr add <message_id> <role> <label> [emoji] [style]

Add a button to an existing panel. Message ID can be found by right-clicking the panel message.

REQUIRES: ADMINISTRATOR

/rr edit <message_id> [title] [description] [color] [mode]

Update the appearance or behavior of a panel without recreating it.

REQUIRES: ADMINISTRATOR

/rr list

Displays all active reaction role panels in the current server with their IDs and configuration.

REQUIRES: ADMINISTRATOR

Custom Commands

Create custom trigger-based commands for your server. Free: up to 5 text commands. Pro: up to 30 with embeds, variables, and role actions.

FREE

/customcmd create <name> <trigger> <response>

Create a text command. Trigger must start with a prefix like ! ? . — e.g. !rules.

REQUIRES: MANAGE_SERVER

/customcmd list

List all custom commands with their triggers and features.

REQUIRES: MANAGE_SERVER

/customcmd delete <name>

Delete a custom command.

REQUIRES: MANAGE_SERVER

⭐ PRO ONLY

/customcmd embed <name> [title] [description] [color] [footer] [thumbnail] [image]

Add a rich embed to your command. Variables are supported in all text fields.

REQUIRES: PRO + MANAGE_SERVER

/customcmd restrict <name> [role] [channel] [clear]

Restrict who can use a command by role or which channels it works in.

REQUIRES: PRO + MANAGE_SERVER

Give or remove a role automatically when the command is triggered.

REQUIRES: PRO + MANAGE_SERVER

/customcmd variables

View all available placeholders: {user}, {server}, {membercount}, {channel}, {date}, {time}, and more.

REQUIRES: PRO

.13

Starboard

A community-curated "best of" channel. When a message gets enough star reactions, it's automatically reposted to a starboard channel with the content, images, and a jump link.

/starboard setup <channel>

Set the starboard channel and enable the system. All starred messages will appear here.

REQUIRES: MANAGE_SERVER

/starboard config [emoji] [threshold] [self-star] [allow-nsfw]

Customize the star emoji (default: ⭐), minimum stars needed (default: 3), whether users can star their own messages, and NSFW filtering. Run without options to view current settings.

REQUIRES: MANAGE_SERVER

/starboard ignore [channel] [role] [clear]

Block specific channels or roles from appearing on the starboard. Use clear:True to reset all ignores. Toggles on/off per channel/role.

REQUIRES: MANAGE_SERVER

/starboard disable

Turn off the starboard. Use /starboard setup to re-enable.

REQUIRES: MANAGE_SERVER

/starboard stats

View starboard statistics: total posts, current threshold, and active status.

REQUIRES: MANAGE_SERVER

Run timed giveaways with button entry, automatic winner selection, and rerolls. Up to 5 active giveaways per server. Fully persistent — survives bot restarts.

/giveaway create <prize> <duration> [winners] [channel] [required-role]

Start a new giveaway. Duration supports 30m, 1h, 2d, 1w. Max 30 days, up to 20 winners. Optionally require a role to enter.

REQUIRES: MANAGE_SERVER

/giveaway end <message-id>

End a giveaway early and immediately pick winners.

REQUIRES: MANAGE_SERVER

/giveaway reroll <message-id> [count]

Pick new winner(s) from remaining entries for an ended giveaway.

REQUIRES: MANAGE_SERVER

/giveaway list

View all active giveaways with entries, winners, and time remaining.

REQUIRES: MANAGE_SERVER

PRO .16

Anti-Raid

Join flood detection with auto-scaling thresholds. Detects suspicious join patterns and triggers lockdown, kicks, and auto-unlock. Requires Altair Pro.

/promod antiraid <enabled> [threshold] [window] [lockdown] [kick] [autounlock]

Enable or configure anti-raid. Set the join threshold (0 = auto-scale based on server size), detection window in seconds (10-120, default 30), and choose actions: auto-lockdown, kick suspicious accounts, and auto-unlock after cooldown.

REQUIRES: ADMINISTRATOR • PRO

PRO .17

Phishing Detection

Scam and phishing link detection using a database of 36,000+ known malicious domains with lookalike domain analysis.

/promod phishing <enabled> [action] [lookalikes] [trust]

Enable phishing link scanning. Choose an action on detection: Delete + Warn, Delete Only, or Warn Only. Toggle lookalike domain detection (catches domains that look like discord.com, steam, etc). Add trusted domains that should never be flagged.

REQUIRES: ADMINISTRATOR • PRO

PRO .18

Duplicate Detection

Detects repeated messages from the same or different users. Catches copypasta spam, raid messages, and repetitive content.

/promod duplicates <enabled> [window] [repeats] [crosschannel] [crossuser] [action]

Configure duplicate detection. Set the detection window (10-300s, default 60), max allowed repeats (2-10, default 3), and whether to detect across channels or users. Action choices: Delete + Warn, Warn Only, or Delete Only.

REQUIRES: ADMINISTRATOR • PRO

PRO .19

Account Gating

New account filtering. Flag or restrict accounts that are too new, have no avatar, or look suspicious. Useful for preventing alt abuse.

/promod accountgate <enabled> [minage] [role] [action] [avatar]

Configure account gating. Set the minimum account age in days (1-365, default 7). Assign a quarantine role to restrict new accounts. Actions: Quarantine (restrict channels), Kick, or Alert Only. Optionally require an avatar.

REQUIRES: ADMINISTRATOR • PRO

PRO .20

Auto-Slowmode

Dynamic slowmode that activates automatically when chat activity spikes. Adapts in real-time with tiered thresholds (moderate, high, extreme) and lifts when things calm down.

/promod slowmode <enabled> [window] [cooldown] [ignore] [log]

Enable auto-slowmode. Set the monitoring window (5-60s, default 10), cooldown before removing slowmode (10-300s, default 30), add channels to the ignore list (like bot-command channels), and toggle logging of slowmode changes.

REQUIRES: ADMINISTRATOR • PRO

PRO .21

Attachment Filtering

Control file uploads in your server. Block dangerous file types, set up media-only channels, and enforce file size limits.

/promod attachments <enabled> [mediaonly] [block] [unblock] [action]

Configure attachment filtering. Add media-only channels (only images/videos allowed). Block specific file extensions (like exe, bat, scr) or unblock them. Action choices: Delete + Warn, Delete Only, or Warn Only.

REQUIRES: ADMINISTRATOR • PRO

PRO .22

Regex Filters

Create custom regex-based content filters. Match patterns in messages and take action automatically. Supports test mode for safe testing.

/promod regex <action> [name] [pattern] [reason] [testmode]

Manage regex filters. Actions: Add a filter (requires name + pattern), Remove a filter (by name), List all filters, or Enable/Disable the system. Test mode logs matches without taking action so you can fine-tune patterns.

REQUIRES: ADMINISTRATOR • PRO

PRO .23

Auto-Purge

Automatically clean up old messages in specified channels on a schedule. Great for bot-spam channels, temp channels, and keeping things tidy.

/promod autopurge <action> [channel] [maxage] [botsonly] [excludepinned]

Manage auto-purge. Actions: Add a channel (set max message age 1-336 hours, default 24), Remove a channel, List configured channels, or Enable/Disable. Options: only purge bot messages, skip pinned messages.

REQUIRES: ADMINISTRATOR • PRO
